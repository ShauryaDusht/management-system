Install the IITGN certificate once so this phone can open the management apps securely.

Download IITGN CA Certificate

Download the certificate first, then follow the steps for your device. This page works before the certificate is installed.

Android (Samsung One UI)

  1. Open {{ download_url }} in Chrome. The file downloads automatically.
  2. Open Settings and search for Install certificates in the search bar.
  3. Tap Install from device storage.
  4. Select the downloaded ca.crt file.
  5. When prompted for certificate type, select CA Certificate.
  6. Give it a name like IITGN-Management.
  7. Return to this page and tap the button at the bottom.

iOS (iPhone or iPad)

  1. Open {{ download_url }} in Safari and tap Allow to download the profile.
  2. Open Settings > General > VPN and Device Management.
  3. Tap the downloaded profile, tap Install, then enter the passcode.
  4. Open Settings > General > About > Certificate Trust Settings.
  5. Enable full trust for IITGN-Management.
  6. Return to this page and tap the button below.
